# Device labs

Core curriculum: build instruments, hit FreeRTOS problems on the LCD and
speaker. One ESP-IDF project: `labs/device-labs`.

```text
cd labs/device-labs   # or sticky project after init
rbdev run 00
```

Select the **lab** with `rbdev run NN`. Select the **step** in `exNN.c`
(`exNN_stepMM_start()`). Details: [labs/device-labs/README.md](../../../labs/device-labs/README.md)
(source in the repo — generated pages follow).
