SymptomFix
rbdev: command not found Open workshop root in Cursor; new terminal; or call rbdev/<os>/rbdev; Windows: start-here.cmd

Bare run 00 → nvm / OneDrive Always rbdev run 00
Not an ESP-IDF project Run from workshop root after init, or cd labs/<track>, or --project …
Serial port not present / cannot open port rbdev config --port COMx; unplug/replug; close other monitors
Wrong board / GPIO rbdev config --board … then reconfigure
target esp32 rbdev init again for that project (set-target esp32s3)
