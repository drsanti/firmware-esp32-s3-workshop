rbdev user manual

Complete guide to the workshop host CLI: enroll once with init, flash labs with run, and use the full Espressif idf.py workflow without export.ps1.

CLI 0.1.2+ ESP-IDF v6.1 Target esp32s3 Boards ws28p · es3c28p
One tool for class Use rbdev only. Do not run ESP-IDF export.ps1 / export.sh, and do not type bare run 00 (on Windows that often hits nvm). PowerShell is not required — Cursor terminal or cmd is fine.

What rbdev does

rbdev finds the course ESP-IDF install, repairs the Espressif Python venv when needed, remembers your serial port and board in a sticky .rbdev.toml, selects a lab exercise, then builds and flashes with -DBOARD=. After init, plain idf.py … works through a shim that loads the same environment.

Memorize these

rbdev init                 # once (pick device-labs)
# open a NEW terminal tab
rbdev doctor               # when anything looks wrong
rbdev run 00               # select lab + build + flash
rbdev run 00 --monitor     # same + serial monitor
rbdev config --port COMx   # after USB re-plug

idf.py menuconfig          # full ESP-IDF (after init)
rbdev idf -- fullclean     # same without PATH shim
