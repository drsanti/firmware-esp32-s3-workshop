Configuration

Sticky .rbdev.toml, boards, environment variables, and Cursor PATH settings.

.rbdev.toml (gitignored)

Written by rbdev init and rbdev config at the workshop root. Each field includes # comments explaining when to change it. See .rbdev.toml.example in the repo.

KeyMeaningWhen to change
default_board ws28p or es3c28p for -DBOARD= Switch hardware; or rbdev config --board …
default_port Sticky serial / ESPPORT USB re-plug changes COM / cu / tty
default_esp_idf_path ESP-IDF tree on this PC IDF moved/reinstalled; or re-run init
default_esp_target Chip for set-target (workshop: esp32s3) Almost never
workshop_root Absolute path to this clone Folder moved/renamed → re-run init
default_project Sticky track name for run from workshop root New default track; or just cd labs/…
[[projects]] Catalog of apps (relative paths) Almost never — init refreshes
Paths use forward slashes Example: D:/dev/esp/v6.1/esp-idf — avoid backslashes in the TOML.

Boards

SKUProduct
ws28pWaveshare ESP32-S3-Touch-LCD-2.8 (default)
es3c28pTernion ESP32-S3
 
rbdev config --board ws28p
rbdev flash --board es3c28p -p COM6    # one-shot override
rbdev reconfigure --board es3c28p

Environment variables

VariableRole
ESPPORT / RBDEV_PORTOverride sticky serial (wins over .rbdev.toml; rbdev warns if they differ)
RBDEV_BOARDOverride default board
RBDEV_IDF_PATH / IDF_PATHPrefer an IDF tree during discovery
RBDEV_WORKSHOPWorkshop root override
RBDEV_SDK_ROOTManaged SDK root (Path B / setup)
 
# PowerShell
$env:ESPPORT = "COM17"
$env:IDF_PATH = "C:\Espressif\frameworks\esp-idf-v6.1"

# bash
export ESPPORT=/dev/ttyACM0
export RBDEV_IDF_PATH=~/esp/esp-idf

IDF discovery order

  1. Sticky default_esp_idf_path
  2. RBDEV_IDF_PATH
  3. IDF_PATH
  4. Espressif EIM registry
  5. Common install folders

Cursor / VS Code settings

Committed file: .vscode/settings.json. Prepends LocalAppData / home shims and rbdev/<os> onto the integrated terminal PATH. Keep it in git; do not delete.

Project resolution (runtime)

  1. Explicit --project
  2. Walk up from cwd for ESP-IDF app (CMakeLists.txt + main/)
  3. Sticky default_project under workshop root
  4. Error with hint to run init or cd labs/…
