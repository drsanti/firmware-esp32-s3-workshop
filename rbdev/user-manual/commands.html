Command reference

Student commands first, then IDF step wrappers, then instructor tools. Run rbdev --help for the live list.

Student commands

rbdev init

First-run enroll: find IDF, repair venv, write .rbdev.toml, set-target, PATH/shims.

rbdev init
rbdev init --project device-labs --port auto --board ws28p -y
rbdev init --idf-path D:/dev/esp/v6.1/esp-idf --project device-labs -y
rbdev init --skip-install --no-add-path -y --project device-labs --port COM17

rbdev doctor

Preflight: SDK / IDF_PATH, workshop lib/, serial ports, Python rich_click.

rbdev doctor
rbdev doctor --json
rbdev doctor --workshop .
ExitMeaningFix
0OK—
10No SDK / IDFInstall ESP-IDF or set path; Path B: setup --offline
11Missing lib/ / headersUpdate workshop clone / restore firmware package
12No serial portCable, driver, close other monitors, set port

rbdev run [NN]

Select lab in main/main.c, then build + flash (optional monitor).

rbdev run
rbdev run 00
rbdev run 00 --monitor
rbdev run 00 -m -p COM17
rbdev run 06 --select-only
rbdev run 12 --project labs/rtos-labs
rbdev run 01 --board es3c28p

rbdev config

Save or show sticky port/board (writes .rbdev.toml with comments).

rbdev config --show
rbdev config --port COM17
rbdev config --port COM17 --board ws28p
rbdev config --board es3c28p

IDF step wrappers

Same environment as rbdev idf --; inject -DBOARD= and sticky port where needed.

rbdev build
rbdev build --board es3c28p
rbdev reconfigure
rbdev flash -p COM17
rbdev monitor
rbdev idf -- build flash monitor
rbdev idf -- menuconfig
rbdev idf -- fullclean

Instructor / advanced

rbdev version

rbdev version

rbdev setup (Path B)

Only if the instructor provided a full kit with offline SDK archive.

rbdev setup --offline C:\path\to\kit\sdk\archive.zst
rbdev setup --offline .\sdk --force
rbdev doctor --workshop .

rbdev flash-bin

Flash a prebuilt image folder (flash_args + bins) via esptool — no IDF build.

rbdev flash-bin --port COM17
rbdev flash-bin --dir firmware-prebuilt/ws28p -p COM17 --baud 460800

rbdev shell

Interactive shell with IDF env injected (PowerShell on Windows).

rbdev shell

rbdev fw sync

Install librobotos_fw.a + public headers into the workshop.

rbdev fw sync --from robotos-fw-….tar.gz
rbdev fw sync --from https://example/robotos-fw.tgz --sha256 <hex>
