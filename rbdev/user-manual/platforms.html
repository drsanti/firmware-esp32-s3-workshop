Windows · macOS · Linux

Same commands everywhere — binary path and serial device names differ.

WindowsmacOSLinux
First-run binary rbdev/windows/rbdev.exe rbdev/mac/rbdev rbdev/linux/rbdev
After PATH rbdev … rbdev … rbdev …
Serial examples COM6, COM17 /dev/cu.usbmodem… /dev/ttyACM0, /dev/ttyUSB0
Extra once Optional start-here.cmd chmod +x + Gatekeeper Open chmod +x + dialout group
Stable shim dir %LOCALAPPDATA%\rbdev\bin ~/.local/share/rbdev/bin

Windows

git clone https://github.com/drsanti/firmware-esp32-s3-workshop.git
cd firmware-esp32-s3-workshop
# Cursor terminal:
rbdev init
# fallback:
.\rbdev\windows\rbdev.exe init

# NEW terminal
rbdev doctor
rbdev run 00
  • Shells: Cursor terminal or cmd — PowerShell is not required.
  • Never type bare run 00 (often hits nvm).
  • Outside Cursor: double-click start-here.cmd.
  • Git Bash: prefer rbdev-cli.exe or cmd //c rbdev … (shims are .cmd).

macOS

chmod +x rbdev/mac/rbdev
./rbdev/mac/rbdev init
# Gatekeeper: right-click → Open once if blocked
# NEW terminal
rbdev run 00

Prefer /dev/cu.* over /dev/tty.* for serial.

Linux

chmod +x rbdev/linux/rbdev
sudo usermod -aG dialout "$USER"   # then log out/in
./rbdev/linux/rbdev init
# NEW terminal
rbdev run 00
